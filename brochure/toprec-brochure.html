Introduction
Platform Overview
Everything you need to manage professional town planning licenses in Nigeria — in one unified platform.

The TOPREC Admin Portal is a purpose-built web application designed for the Town Planners Registration Council of Nigeria. It provides registered town planners, consulting firms, and practice firms with a secure, modern interface to manage their professional licenses, process payments, maintain profiles, and stay compliant with regulatory requirements.


Administrators and super-administrators gain access to a comprehensive member directory, payment configuration tools, and real-time oversight of the entire membership base. The platform replaces manual, paper-based workflows with a streamlined digital experience — from initial registration through annual license renewal.

Authentication & Onboarding
Module 01
Authentication & Security
Enterprise-grade authentication with JWT tokens, OTP verification, and automatic session management to protect every account.
🔑
Secure Login
Authenticate using your TOPREC registration number (e.g., RTP/1*** or PFN/5**) and password. Features include:
  • Password visibility toggle
  • Real-time field validation
  • Loading state with animated spinner
  • Auto-redirect to dashboard on success
  • Existing-user profile update modal
📝
Member Registration
Full sign-up flow with role selection and comprehensive form collection:
  • Role: Member, Consulting Firm, or Practice Firm
  • Personal Info: name, email, phone, address, gender
  • Professional: registration number, state, date
  • Security: password with strength requirements
  • Conditional fields based on selected role
🔄
Password Recovery
Multi-step password recovery with OTP verification for identity assurance:
  • Enter email or registration number
  • Receive 6-digit OTP via email
  • Verify OTP with cooldown-based resend
  • Set new password (min. 6 characters)
  • Auto-redirect to login on success
🛡
Session Management
Robust token-based session handling to ensure secure, uninterrupted usage:
  • JWT access & refresh token architecture
  • Automatic token refresh 5 min before expiry
  • Persistent login via localStorage
  • Route guards: AuthGuard & NoAuthGuard
  • Global error interceptor for 401/403

Module 02
Dashboard Home
A personalised command centre providing real-time visibility into license status, financial standing, and profile health at a glance.
📊
Key Metrics Dashboard

Statistics Cards

  • License Status — Active, Expired, or Blocked badge with days-remaining countdown
  • Levy Balance — Outstanding balance in Nigerian Naira (₦) with Clear/Outstanding indicator
  • Profile Completion — Percentage progress bar showing X/Y fields completed, clickable to navigate to profile

Quick Actions

  • Update Profile — One-click navigation to edit personal information
  • Make Payment — Direct access to license renewal payment processing
  • View License — Instant access to view and download your practice license
🔔
Smart Alerts & Banners
Context-aware notification banners that appear automatically based on your account status:
  • License Renewal Reminder — Appears when license expires within 60 days, with gradient green banner and “Renew Now” call-to-action
  • Outstanding Levy Warning — Red gradient alert when financial obligations are pending, with “Pay Now” button
📅
License Validity Tracker
Visual representation of your annual license period with real-time progress tracking:
  • Horizontal progress bar showing elapsed days in the calendar year
  • Issued date to expiry date range display (Jan 1 – Dec 31)
  • Colour-coded status: green (safe), orange (expiring soon), red (expired)

Personalised Welcome Experience

The dashboard greets each user by their first name alongside the current date. The license status badge is prominently displayed in the header — providing instant clarity on whether the user's license is Active, Expired, or Blocked, ensuring compliance awareness from the moment they log in.

Module 03
Profile Management
Complete professional profile with photo management, editable fields, and read-only regulatory data — ensuring accuracy while giving users control over their contact details.
👤
Profile Card & Photo Management

Profile Header

  • Professional gradient header with avatar display
  • Profile photo upload (JPEG, PNG, WebP — max 5 MB)
  • Initials fallback when no photo is uploaded
  • Camera icon overlay for quick photo change
  • Upload & remove photo actions with loading states
  • Membership ID and “Active Member” badges

Edit & View Modes

  • Toggle between view and edit modes
  • Visual distinction: disabled fields shown in grey
  • Cancel reverts all changes to original values
  • Save button disabled until form is valid
  • Success/error alerts with auto-dismiss (3 seconds)
  • Loading spinner during data fetch
📋
Personal Information
Core personal details with appropriate edit permissions:
  • Full Name — Read-only; requires contacting TOPREC support to change
  • Email Address — Editable with email format validation
  • Phone Number — Editable with +234 Nigerian format
  • Address — Editable, minimum 5 characters
  • Gender — Editable dropdown (Members only): Male, Female, Other, Prefer not to say
🏛
Professional Information
Regulatory data managed by the council:
  • Membership Number — Read-only; issued by TOPREC
  • State of Practice — Editable dropdown populated from API with all Nigerian states
  • Date of Registration — Read-only; set at account creation
  • Tooltips on read-only fields explain why they cannot be changed
  • Red asterisks mark all required fields

Data Integrity Safeguards

Critical regulatory fields — Full Name, Membership Number, and Registration Date — are locked to prevent unauthorised modifications. Users wishing to correct these fields are guided to contact TOPREC help and support via informational tooltips, maintaining the integrity of the professional registry.

Member Administration
Module 06
Members Directory
A centralised administration hub exclusively for super-administrators — providing full visibility and management control over the entire TOPREC membership base.
👥
Three-Tab Directory View
The directory is organized into three distinct categories, each with dedicated count badges, search, and filtering capabilities:

Directory Categories

  • Members — Individual registered town planners with personal details, registration numbers, and practice status
  • Consulting Firms — Registered consulting organisations authorised for large-scale planning projects (master plans, EIS, campus plans, subdivisions > 10 hectares)
  • Practice Firms — Registered firms authorised for site analysis, smaller layouts (< 10 hectares), development permits, and advisory services

Management Features

  • Quick stats dashboard showing total and active member counts
  • Unified search across name, email, and registration number
  • Status filter dropdown (Active, Inactive, Pending, etc.)
  • Category-specific count badges on each tab
  • Tabular view with full contact information
  • View, edit, and manage individual member records
🔎
Search & Filter
Powerful tools to quickly locate specific members in large directories:
  • Full-text search across all member fields
  • Status-based filtering (Active, Inactive, Suspended, Pending)
  • Category-based filtering by role type
  • Real-time result updates as filters are applied
📊
Statistics Dashboard
At-a-glance metrics for workforce oversight:
  • Total Members — Blue badge showing aggregate count across all roles
  • Active Members — Green badge showing currently active registrations
  • Per-tab count badges for Members, Consulting Firms, and Practice Firms
  • Real-time data refresh from the member API

Superadmin Exclusive

The Members Directory is restricted to users with the Superadmin role. The sidebar navigation item is dynamically hidden for all other roles through role-based menu filtering, and route guards enforce access control at the application level.

Security Architecture

Authentication Layer

  • AuthGuard — Protects all dashboard routes; redirects unauthenticated users to login
  • NoAuthGuard — Prevents authenticated users from accessing login/signup pages
  • Auth Interceptor — Injects Bearer token into every outbound HTTP request

Error Handling

  • Error Interceptor — Catches all HTTP errors globally (401, 403, 500, etc.)
  • Automatic session invalidation on authentication failures
  • User-friendly error messages via the notification service
